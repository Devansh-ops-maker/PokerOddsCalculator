# Poker Odds Calculator

Poker Odds Calculator is a web-based application that calculates the probability of winning in Texas Hold’em poker using Monte Carlo Simulation. The project allows users to select their hole cards, community cards, and the number of players at the table through the interface.

The backend is built using FastAPI and performs thousands of randomized simulations to estimate the player’s winning probability against unknown opponent hands.

The application evaluates poker hands in real time and returns accurate winning probabilities based on the currently known cards.
